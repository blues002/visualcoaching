# visualcoaching

비주얼코칭센터 작업 관리 저장소. 할 일은 GitHub Issues에 하나씩 올리고, 슬랙에서 나온 일도 여기로 모은다.

## 작업 올리는 법

Issues → New issue에서 양식을 고른다.

- 작업: 영역, 우선순위, 마감일, 단계 체크리스트. 슬랙에서 나온 일이면 메시지 링크를 붙이고 `슬랙` 라벨을 단다.
- 강의·워크숍 의뢰: 기관 문의가 들어오면 바로 하나 만든다. 사전신청설문지 발송부터 강사료 세무 처리까지 체크리스트가 들어 있다.

끝난 작업은 Close. 상대 답을 기다리는 중이면 `대기` 라벨.

## 라벨

`.github/labels.json`에 정의되어 있다. main 브랜치에 이 파일이 바뀌면 GitHub Actions가 라벨을 자동으로 만들거나 고친다. 처음 한 번은 Actions 탭 → 라벨 동기화 → Run workflow로 직접 돌리면 된다.

| 종류 | 라벨 |
|---|---|
| 영역 | 강의·워크숍, 코칭, 작은도서관·화도연, 박사논문, 콘텐츠, 운영·행정 |
| 우선순위 | 우선순위: 높음 / 보통 / 낮음 |
| 상태·출처 | 대기, 슬랙, 작업 |
